# selfwriting 1.15.0

一款**离线优先**的创作应用（安卓 APK + PWA）：小说 / 文章 / 日记 / 大纲 / 阅读器 / 音乐 / 成就系统。
所有内容保存在你自己的设备上：没有账号服务器、没有遥测、没有广告、没有云同步。

## ✅ 离线功能（飞行模式也能用）

- **小说**：分章节写作、章节字数目标与进度、大纲双向联动、本地启发式续写辅助、导出 TXT / Markdown
- **文章 / 大纲**：长文写作与字数目标；大纲彩色分支树、重点标记、与章节互链
- **日记日历**：农历 / 节气 / 节日 / 法定假期 / 公休（工作日黄底、休息日绿底）、圆形日期 + 当天篇数角标、**点日期直接写**、**双击收藏**、**长按弹「选这几天」写跨天日记**、周记 / 月记 / 自定义间隔汇总、心情天气标签、插图
- **阅读器**：导入 TXT / Markdown / HTML / EPUB / MOBI / AZW3 / PRC / PDF；渐进渲染（300 章的书首屏同步渲染约 10 ms）；**仿真卷曲翻页**（手指跟随卷边、露纸背、松手回弹）；连续滚动 / 覆盖翻页 / 平移 / 卷曲四种翻页方式；单双列书架 + 封面宽度可调；书签点亮 + 目录命中标记；收藏爱心；字数上万用「万」
- **音乐**：真采样音色（钢琴 / 电钢琴 / 吉他 / 贝斯，FluidR3_GM，CC BY 3.0）+ 合成鼓组；试音台；**示例曲库可选**；**导入并演奏**（粘贴简谱，或导入 MIDI / 本应用导出的曲子）；16 步谱曲；歌词
- **账号与状态**：**只存在本机**的资料（昵称 / 头像 / 专属码）、仿微信 QQ 的时效状态、密友名单、作品多人创作标记
- **协作**：同一 Wi-Fi 开房 / 加入、段落级合并（不覆盖不丢内容）、房间内对话、分享包
- **成就与统计**：各模块独立成就、创作时长 / 字数 / 速度 / 停笔间隔 / 热力图、整库 JSON 备份
- **其他**：俄罗斯方块、贪吃蛇、计算器（标准 / 科学 / 单位换算 / 历史）、便签、隐私锁、亮度与深色 / 护眼主题、三种界面语言（简体中文 / English / 繁體中文）

## 🌐 联网功能（全部手动触发，无后台联网）

| 场景 | 说明 |
| --- | --- |
| 阅读器 → 网址下载 | 粘贴书籍 URL，下载并导入；只在点「开始下载」时请求该地址 |
| 协作室 | 走你自建的本机 / 局域网服务，**不出局域网** |
| 安装 APK / 添加桌面 | 用本机服务把安装包发给手机，或把网页版加到主屏幕 |

除此之外**不发起任何网络请求**。

## ⚠️ 已知不足（如实标注）

- **续写辅助是本地启发式，不是 AI 大模型**（应用离线）；候选一定是你点选后才插入
- **协作**为段落级合并：保证不覆盖不丢内容，但多人**同一毫秒写同一段**时顺序无法保证唯一
- **隐私锁是应用内访问锁，不是加密**：密码为加盐哈希；设备被拿到且对方能连电脑调试时，本地数据仍可能被读走
- **PDF** 只提取文本层，扫描版 PDF（图片）提取不出内容；**HUFF/CDIC 压缩的 MOBI** 暂不支持
- **农历**表覆盖 1900–2100（已逐日与参考实现比对 73,384 天无差异）；**节气用近似公式，允许 ±1 天误差**；法定假期精确覆盖 2024 / 2025 / 2026，其余年份按规则推算，**个别调休日可能不准**（只影响日历底色与注解）
- **鼓组仍是合成音**（未找到许可清晰的打击乐素材）；钢琴 / 电钢 / 吉他 / 贝斯为真采样
- **卷曲翻页**用 DOM + clip-path 实现，低端机大量阴影可能掉帧；没有真实纸张纹理与光照模型
- **桌宠（SVG 布偶猫）已移除**：观感不理想，源码保留在 `js/pet.js`、`js/view-pet.js`、`css/pet.css` 并标注「已停用」，想启用把 `index.html` / `sw.js` 里的引用加回去即可
- **平台**：安卓 7.0+ / 桌面浏览器；iOS 未适配（PWA 可能可用但未测试）
- 带 **DRM** 的电子书无法导入（本应用不解 DRM，也不应解）

## 🔒 多用户与隐私

- **账号只在本机**：昵称 / 头像 / 专属码写在这台设备的存储里，**从不上传**，安装包与本仓库也不含任何人的资料
- **每个人各自一份数据**：换人使用就在他的设备上注册他自己的账号；A 的作品、日记、导入的书都在 A 的设备上，开发者本人都看不到
- **重新打开（重新登录）后照常加载**：内容保存在本机 IndexedDB + localStorage（双写兜底）；重开应用、改昵称头像、重新注册都不会动内容；换设备用「设置 → 导出整库备份 / 恢复备份」
- **卸载或清浏览器数据会删掉本机内容**，建议定期导出备份
